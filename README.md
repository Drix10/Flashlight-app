# Flashlight App for Android (MIT App Inventor)

A one-tap **flashlight app for Android** with on/off buttons. Built with [MIT App Inventor](https://appinventor.mit.edu/), a block-based tool for making Android apps.

## Files

- `Flashlight.aia`: the App Inventor project (import this)
- `Screen1.scm`, `Screen1.bky`: layout and blocks
- `ON.png`, `OFF.png`: button images
- Flashlight extension files (`classes.jar`, `components.json`)

## Open it

In [MIT App Inventor](https://ai2.appinventor.mit.edu/), choose **Projects → Import project (.aia)** and select `Flashlight.aia`.
